PRIVATE BY DESIGN

Your project map stays yours.

Atlas is a static browser app. It has no account, analytics, or service that receives your map.

Local to this browser

Maps and edits are kept in browser storage. Atlas does not upload repository files or graph data. Clearing this browser’s storage removes local maps, so export a JSON backup first if you want to keep them.

Back up when you need to

Export JSON to move a map to another browser or keep an offline copy. You decide where that file goes.

Share intentionally

A share link carries a snapshot in its URL fragment, after #; that fragment is not sent in the page request. Anyone with the full link can open that snapshot. A recipient edits their own copy, which does not change yours.

Agent access is separate: the copied prompt goes to the coding agent you choose. That agent's own data handling applies; Atlas does not read your repository.
