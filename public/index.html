PRIVATE BY DESIGN

Your project map stays yours.

Atlas starts in your browser, without an account. Sign-in gives you access to account maps; future maps upload only if you separately enable that preference. Online links are live and view-only. Atlas has no analytics or AI service.

Local to this browser

Maps and edits are kept in browser storage by default. Signing in alone does not upload maps. If you turn on save-new-maps in Settings, future maps upload to your account; existing local maps stay here until you choose to move one. Atlas never uploads repository files. Clearing this browser's storage removes local maps, so export a JSON backup first if you want to keep them.

Back up when you need to

Export JSON to move a map to another browser or keep an offline copy. You decide where that file goes.

Share intentionally

Local links contain independent snapshots. Optional online links open your live map: only you edit it, and you can stop sharing or delete it. Anyone with an enabled online link can view its content; share only information suitable for recipients.

Agent access is separate: the copied prompt goes to the coding agent you choose. That agent's own data handling applies; Atlas does not read your repository.
